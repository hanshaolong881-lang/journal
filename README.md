# 日省 · Daily Reflection（v2 优化版）

暗金极简 · 密码保护 · 支持全文搜索、在线增删改、离线缓存与手机 PWA 安装。

## 快捷使用

1. **本地直接预览**：双击打开 `docs/index.html`（或桌面 `日省-优化版/index.html`），输入密码即可查看与导出全部记录。
2. **一键发布到线上 GitHub Pages**：双击 `一键更新线上网站.bat`（或桌面的 `日省-一键同步上线.bat`），无需安装 `git`，自动通过加密令牌同步部署到 <https://hanshaolong881-lang.github.io/journal/>（约 30–60 秒生效）。
3. **本地记事本写日记并发布**：双击 `日记.bat`。
4. **手机当成 App 用**：手机浏览器打开线上地址后，点击浏览器菜单「添加到主屏幕」，即可以全屏独立黑金图标运行。

## v2 核心优化清单

- **修复手机端布局错乱**：修正 `@media` 级联顺序，手机端筛选栏与统计卡片自适应无横向溢出。
- **修复按月筛选与跨零点时区少一天 Bug**：不再使用 UTC `.toISOString()`，6 月 30 日、1 月 31 日及凌晨写日记均精准对应本地日期。
- **新增在线「编辑 / 删除 / 复制」与防连点重复提交**：每张卡片支持原位编辑、单篇删除与一键复制，自动过滤连续重复提交内容。
- **新增全文检索与高亮、统计概览、一键导出 Markdown 全集、全部展开/收起**。
- **置顶编辑器 + 自动草稿暂存 + 快捷主题模板（晨间立意 / 交易复盘 / 言行自省等）+ `Ctrl+Enter` 快捷键**。
- **性能与加载提速**：背景图从 `2.52 MB` 压缩至 `80 KB` WebP（体积减少 96%），改用独立固定图层消除手机滚动抖动；GitHub 同步改为基于文件 `SHA` 的并行增量拉取 + 本地缓存秒开；异步加载霞鹜文楷屏幕阅读版字体。
- **会话保持与一键锁定**：刷新页面不掉锁，可选“此设备保持解锁 7 天”，顶部随时一键锁定。
